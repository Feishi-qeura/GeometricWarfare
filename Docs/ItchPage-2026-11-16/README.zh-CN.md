# itch.io「详情」交付

按你的最新要求，页面正文为纯英文。

## 文件

- `preview.html`：带 7 张配图的完整本地预览，可以直接用浏览器打开。
- `itch-details.md`：完整文案、图片位置和英文图片说明，方便修改。
- `itch-details-text.html`：只有正文和排版的 HTML，适合粘贴到详情编辑器的 HTML/源码模式。不要把本地预览整页的代码粘进去。
- `itch-details.txt`：纯文本版本，可在富文本编辑器里粘贴并手动设置标题。
- `images/`：按页面顺序编号的 7 张 JPG，保留游戏原始画面比例，便于上传。
- `screenshot-map.csv`：每张图对应的原始文件、放置段落和英文说明。

## 放到 itch.io

1. 打开你的游戏编辑页：https://itch.io/game/edit/5249177 。
2. 在「详情 / Description」中粘贴 `itch-details.txt` 的正文；也可以在编辑器的 HTML/源码模式里粘贴 `itch-details-text.html` 的内容。
3. 按 `screenshot-map.csv` 的位置上传 `images/` 里的图片。推荐使用正文宽度，保留原比例。
4. 预览文字、图片顺序与移动端效果后保存。

`preview.html` 和 Markdown 里的图片是本地相对路径，不能直接作为 itch.io 上的图片地址。图片需要在 itch.io 编辑器上传后由平台托管。
