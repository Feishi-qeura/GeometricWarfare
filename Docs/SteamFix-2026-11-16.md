# Steam 非库游戏启动修复与 Windows 图标

交付位置：`D:\demo\GeometricWarfare_DEMO`，Win64 Development，测试 AppID 480。

## 原因与修改

Steam 的 `gameprocess_log.txt` 显示，直接启动旧包时身份为 480，创建好友房成功；通过非 Steam 游戏快捷方式启动时身份为 16375324068921999360，游戏日志出现 `ConnectToGlobalUser failed`，SteamSockets 随之禁用。

对同一个旧 EXE 做对照复现：继承快捷方式 AppID/GameID 时初始化失败，仅将两个进程环境值设为 480 后初始化成功。插件原先只注入 ini 中的 SteamDevAppId，无法消除继承的快捷方式环境身份。

`FU_SteamAppIdBootstrap` 现在在配置校验通过后、Steam API 初始化前，将打包开发游戏进程的 SteamAppId 和 SteamGameId 设为配置中的开发 AppID。编辑器、命令行工具、专用服务器和 Shipping 不应用此修正；卸载时仅恢复仍由本模块持有的环境值。现有游戏内邀请与加入流程继续使用同一个 Steam lobby。

使用现有 `Docs/PressKit/2026-10-28/05-icon.png` 生成 `Build/Windows/Application.ico`，包含 16、24、32、40、48、64、128、256 px。启动器和实际游戏 EXE 均嵌入该图标。

打包脚本补齐两个 EXE 入口旁的 steam_appid.txt，支持跳过 ZIP，并拒绝删除已有输出目录。
