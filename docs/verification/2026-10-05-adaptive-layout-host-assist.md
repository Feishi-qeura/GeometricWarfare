# 开播画面适配与主播助战（2026-10-05）

## 使用方式

右上角“设置”或 Esc 打开设置。新增“界面布局”（自动 / PC / 移动端）和“开播画面比例”（跟随窗口 / 横屏 16:9 / 横屏 4:3 / 竖屏 9:16 / 横屏 20:17 / 横屏 19:9）。点击选项循环切换，即时生效并保存。恢复性能默认不重置开播布局。自动布局在竖屏使用移动端排版；PC 模式遇到竖屏也使用竖向构图。

横屏保留右侧榜单，竖屏把榜单、玩家详情放到战场下方。移动竖屏参考坐标为 720×1280，9:16 的战场为 688×688；在 1080×1920 画面中，占宽 1032 像素。近方形竖屏也为至少一行榜单与完整详情卡留出空间。所有图形和字体使用相同缩放比例，不拉伸圆形、角色或头像。细节显示阈值按最终像素判断，避免移动布局在高分辨率画面中错误退化成色点。

画面比例控制布局，并不修改模拟世界 8000×8000 的坐标、伤害或积分。固定比例与实际窗口不一致时居中留边；点击、拖动、滚轮和小地图输入使用逆变换，留边不接受战场点击。窗口或布局变化取消未完成的鼠标手势。

Spout 主输出仍固定 **1920×1080**，窗口预览尺寸继续由窗口/平台控制。选择竖屏时，固定横屏输出中是完整竖屏构图加两侧留边；在伴侣中按开播画面进行裁切与等比填充。云端/未来移动画面使用原生竖屏尺寸时直接满宽排版。“移动端”是开播画面布局选项，不代表已交付 Android/iOS 安装包。

9:16 在固定 Spout 输出中的有效画面约为居中 **608×1080**（左右各约 656 像素留边）。伴侣竖屏场景应裁取这块有效画面后等比填充，避免将整张 1920×1080 强制压成竖屏。

## 主播助战

右上角“主播助战”打开独立面板，提供红方、蓝方、灰方三个按钮。首次选择创建一名五角星主播角色，再次选择复用同一身份并切换阵营，自动跟随。主播不占观众名额、不计个人积分、不参与排行榜和评奖。面板关闭后可右键解除跟随；Esc 优先关闭当前面板。面板不暂停对局，打开时拦截战场点击、滚轮、WASD、Home 和右键。

正式运行必须在 SDK 当前会话已连接、当前局的开始回执成功且尚未结算时才能助战。判断同时校验当前游戏轮次、平台局号和会话，排除上一局回执及恢复重放状态。断线、等待开局、结算期间按钮不可用。开发测试使用明确的本地测试模式；Shipping 不提供 GM 面板或模拟观众入口。
