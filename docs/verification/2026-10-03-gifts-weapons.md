# 礼物、永久武器与本地 GM

> 历史验证记录：本文对应当时的战斗/演示版本，保留原始证据与操作过程。2026-10-04 后续平台中立迁移已移除游戏内 GM 与模拟输入面板，插件改为 LiveInteraction；本文旧界面、旧插件路径与当时通过结果不代表当前迁移或真实官方 SDK 验收。

本批次在此前 BOSS、护甲和伤害数字版本上继续实现。最新规则以本文和源码为准。

## 观众操作

- 排行榜前 20 名；阵亡玩家有标记，小窗口可在榜单上滚动查看。
- 冲刺期普通观众（含灰色）不自然复活，普通手动复活也被阻止。主播例外，仙女棒例外。
- 主播核验关注后，发给观众一次性兑换码。评论 `步枪+兑换码` 解锁步枪。
- `武器+1` 至 `武器+6`：手枪、霰弹枪、步枪、狙击枪、机枪、火箭筒。切换显示播报，保留各自弹药、换弹和冷却状态。

| 礼物 | 效果 |
| --- | --- |
| 仙女棒 | 个人复活，冲刺期有效，结算期无效 |
| 能力药丸 | 重建红蓝基地；已存活则当前和最大生命各加 1000。冲刺 / 结算期无效 |
| 魔法镜 | 永久解锁狙击枪·巴雷特 |
| 甜甜圈 | 永久解锁机枪·加特林，装备时移速 ×0.8，七颗子弹在朝向 ±15° 内随机散布 |
| 能量电池 | 永久解锁火箭筒，爆炸面积为八个普通圆的面积（半径 62.2254），对基地伤害 ×2.5 |

前两种礼物进入消息播报；后三种显示图标和持续 2 秒的缓入淡出提示。五张 PNG 原样复制自用户下载目录到 `Content/GiftIcons`，通过 UFS 随打包资源分发。

GM 默认折叠，展开后可滚动；提供锁定测试昵称、清零人数、随机加 50 / 100 人、模拟礼物、生成兑换码。Shipping 构建不显示 GM。清空场地保留永久武器。

## 存档和接入边界

稳定用户 ID 对应 `Saved/SaveGames/ArenaWeaponProgress_v1.sav` 中的武器解锁位图，本地与平台 ID 分开命名空间。跨局、死亡和重启保留，新局满弹。未加入观众收到武器礼物也会保存权益。领取兑换码与武器解锁一起存档，失败不消耗兑换码；武器礼物存盘失败时保留本次运行的权益，每 5 秒重试，成功落盘后保证重启保留。

本批次完成本地存档与规范化 `live_gift` 事件、验证、去重、委托接线。后续抖音云服务、官方关注状态核验、真实礼物 ID 与云同步尚未接入；目前由主播确认关注并发码。未修改提案 DOCX、线上文档或上传任何内容。

## 战斗和显示

- 激光每 0.2 秒 150 基础伤害，狂暴 300，共 15 次。狂暴烧痕自开火起 5 秒，每 0.1 秒 10 基础伤害，最后一秒淡出；BOSS 死亡后仍持续，基地免疫。
- 灰、红、蓝阵营均可获得 BOSS 增益；死亡立即失去。排行榜显示阵营增益、紫色外环、橙色进化方框。
- 进化每 5 秒发射 12 道剑气（两组六道，偏移 30°），射程 1100。
- 修复贴近视口边界时按中心点过早隐藏的问题；形状、头像与描边按真实可见范围裁剪。
- 火箭伤害按爆心到目标外表面的距离衰减；普通形状被动继续生效。机枪 150 次扳机，每次七颗，不是将 150 颗分成七颗一组。
