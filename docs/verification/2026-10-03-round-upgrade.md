# 七分钟战局、英雄与武器平衡

## 已确认规则

- 全局 420 秒，300 秒进入冲刺，结束后 30 秒换局；BOSS 仍在 150 秒出现。
- 死亡失去持分的 20%，击杀者获得同量积分，整数向下取整。剩余 80% 保留；非计分的灰色、主播或环境击杀，将损失部分掉落成积分球，保持其既有不计分规则。
- 红蓝自然复活 15 秒，灰色 20 秒；灰色出生与复活位置改到上方中央。冲刺期普通自然复活仍禁止，仙女棒例外。
- 冲刺进入时排名前十（不含主播/灰色）获得英雄；已阵亡者立即复活。当前/最大生命固定为 2100，护甲 300，每五秒向枪口方向释放六道穿透剑气，30° 扇形，最大行程 650 个普通圆直径（28600），基础伤害 30，对英雄基础伤害 120。全局形状/护甲规则仍适用。剑气飞出竞技场后回收。
- 英雄资格保留到本局结束；之后死亡不自动复活，仙女棒复活后仍是英雄。英雄生命和护甲优先于形状及进化的最大值变化。
- 进化每分钟生成十个，到第六分钟共 60 个；原有 40 秒持续、两组共十二道剑气保留。可计分的进化玩家会把攻击范围内的小球拉向自己，再按普通规则拾取，避免同一个球重复计分。
- 武器箱从第 90 秒起，每 90 秒产生十个，随机狙击枪 / 机枪 / 火箭筒。临时使用一分钟，死亡即结束，不写永久解锁存档。到期恢复之前拥有的武器；永久礼物取得的同款武器不会被到期删除。
- BOSS 16000 生命、40% 血线狂暴，狂暴后承伤 ×0.55。狂暴导弹每次一发瞄准导弹加四发向周围发射的导弹。出生扩散引力波，存活期间将玩家几何体（含主播）引向中央；静止 NPC 保持资源目标定位。击杀奖励同阵营存活者 BOSS 增益和进化，包含灰色和主播。
- 主播基础生命 3000。狙击枪按用户补充调整为射程 4200、距离分界 2400，近距离瞄准 1.5 秒 / 200 基础伤害，远距离瞄准 3 秒 / 300 基础伤害；维持既有三秒射击间隔和形状被动。

## 本次针对性模拟性能

每项 120 步，固定 1/30 秒，第二轮测量的平均 / P95 如下（毫秒）。原始程序、启动脚本、两轮 CSV 和完整条件保存在 `Saved/TargetedPerf/RESULTS.md` 及同目录。

| 场景 | 1000 人 | 5000 人 |
| --- | --- | --- |
| 铺开基线 | 0.525 / 0.545 | 4.772 / 5.291 |
| BOSS 引力聚团 | 3.819 / 5.001 | 20.934 / 23.054 |
| 人为极端重叠 | 4.493 / 7.164 | 30.363 / 38.955 |
| 聚团胜方进化，420 个球 | 2.180 / 3.588 | 13.617 / 18.320 |
| 再加 5000 个掉落球 | 5.883 / 8.139 | 19.943 / 25.797 |

5000 人场景的获奖方为 2000 人。测试关闭战斗与 NPC，不计 UE 渲染；极端重叠 P95 已超过 33.3 毫秒，不能承诺全部工况达到 30 FPS。主要热点是物理求解和接触排序；5420 球对 2000 进化玩家的吸球阶段独立平均约 7.786 毫秒。此次保留正确性与现有碰撞预算，没有为了基准而删减伤害、奖励或人数规则。
