- 礼物三轨同时展示，每条 2.8 秒；同一稳定身份、礼物和结果合并数量，不因持续事件重置展示年龄。超过 256 条待播时新增内容明确汇总为多位观众，保留贡献数量。不同稳定 ID 的同名观众不互相领取权益。Int64 计数溢出时展示下界。
- 个人有效点赞累计 1000 解锁霰弹枪，未加入时先累计进度，加入后领取。当前直播会话跨局 / 死亡保留未达标进度，切换直播会话重置。解锁后成功存档可跨重启保留。分享不再授予武器。关注当前主播由可信平台状态验证并自动永久解锁步枪。
- 已解锁后的重复点赞 / 关注 / 武器礼物不会补弹或重置冷却；结算期可取得永久权益，下一局使用。
