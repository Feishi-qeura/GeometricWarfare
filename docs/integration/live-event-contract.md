# 中立直播事件与关注权益设计

游戏通过 LiveInteraction 消费官方提供者归一化事件，不通过评论伪造关注、分享、礼物或快捷选队。Follow 来源必须匹配当前平台、应用、房间、会话代次与 nonce；只有 TargetUserId 等于当前主播且 Action 为关注或回关才取得关注资格。

当前步枪采用**一次性永久解锁**：主动参与者首次取得有效关注资格后解锁，取消关注不撤回已取得权益，重复关注不重复奖励。未参与者仅缓存资格，随后通过加入或快捷选队主动参与才可获奖；进房本身不会创建角色或直接奖励。进房 FollowStatus 1/2 可用于已主动参与者的资格。该一次性设计与平台关于关注状态持续变化及持续权益的指引仍需产品与平台审核确认，不能据本地回归宣称已满足持续权益要求。

Presence 的毫秒时间戳用于丢弃同一用户旧状态。离房更新存在状态而保留战局角色。InviterId 与 EnterRoomScene 仅保留真实邀请证据；当前分享召集与霰弹枪的正式资格规则未确定，生产模式不发放分享霰弹枪。本地测试 share 保留已有回归行为。

快捷选队仅接受 [LiveInteraction] RedGroupId / BlueGroupId / GrayGroupId 实际配置映射，三者必须非空且唯一。未知 GroupId 不猜测阵营；灰队按钮可主动加入灰色或保持现有灰色身份，已加入红蓝的用户不能回到灰色。已确定阵营的用户不会因为快捷选队更改形状。只有平台 round_start 已确认、LiveRoundId 有效后才由对局 reporter 串行提交并重试 user_group；提交成功不代表平台回执成功。

事件投递成功仅表示游戏消费者接收，不等于履约。游戏实际处理后保留消息 ID 与官方 msg_type，在 HUD 绘制提交后发送 ACK；NullRHI 不发送渲染履约。ACK 请求仍等待异步平台回执，失败保留事件并退避重试，切换会话清除旧队列。此流程仍不替代真实平台测试工具验收或付费礼物的持久去重与失败补偿验证。
