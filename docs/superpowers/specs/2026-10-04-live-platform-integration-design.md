# 可扩展直播平台接入

## 用户目标

将 UE 5.8 几何战争的本地模拟入口替换为正式抖音开放平台能力，插件必须支持未来其他平台。移除 GM 面板。实现已开通且启用的基础能力、基础互动、进阶互动；明确排除观众一键同玩。真实环境联调必须建立在实际 SDK 与控制台配置核验之上。

## 已核验边界（2026-10-04）

- 现有 DouyinLiveBridge 只有模拟器与自定义 WebSocket，不是官方 SDK。
- 官方 LiveOpenSDK 支持指令直推、直播信息、履约 ACK、对局阵营、用户战绩榜单及快捷选队；公开接口为 Unity/C#。
- 本机 BGDT 3.0.271 与官方下载 SHA256 一致，但该包是编辑器管理工具，不包含 LiveOpenSDK 运行库。用户确认尚未取得完整 SDK。
- 基础能力控制台：Spout、进出房、履约、云启动已开通；透明画布已开通但开关关闭；云同步未开通。
- 进阶能力控制台：榜单与快捷选队启用；玩法扩展组件已开通但关闭；观众一键同玩明确排除；同局主播连线未开通。
- 基础互动、开发配置、自查工具与云启动日志仍需读取，不把页面访问失败当作能力不存在。

## 结构

游戏仅依赖平台中立的 LiveInteraction 插件。该插件负责统一事件、平台会话、身份空间、状态、头像与提供者注册接口。抖音专有的 SDK、礼物 ID 映射、启动信息、上报协议留在独立提供者模块，未来平台通过同一接口注册，不修改游戏规则。

不猜测官方 C ABI，不把模拟器或自定义 WebSocket 显示为 SDK 已连接。缺少 SDK 时正式模式保持明确的未配置状态且不自动添加模拟玩家。模拟能力只在显式本地测试模式启用，保留自动化回归入口；默认运行与平台启动必须禁用模拟、加速和测试指令。

已有未提交的规则贴纸 HUD 修改需要保留。移除 Slate GM 面板、F1 入口和提示。镜头、榜单、战斗规则保留。武器权益按平台隔离，迁移不得把本地测试权益归到真实观众。SDK ACK 只能在游戏实际处理后上报；付费消息的持久去重与失败补偿必须独立验证。

## SDK 获取与实现门槛

用已有 Unity 编辑器创建隔离的 SDK 获取工程，导入官方 BGDT 包。开发者主体登录由用户完成。取得 LiveOpenSDK 后检查版本、原生依赖、导出接口、许可与运行环境，再选择 UE 原生包装或受支持的托管桥接；不能提前声称任一路径可用。Spout 必须取得平台指引中的命名、共享纹理与格式要求。不得以其他产品的 PipeSDK 代替直播玩法 SDK。

## 验证

通用层：不同平台相同用户 ID 隔离、缺失提供者状态、会话代次防止旧回调、正式模式拒绝模拟、现有事件/头像/战斗回归。Editor 和 Game 构建。真实验收另需平台启动、房间身份、评论/点赞/礼物/快捷选队/进出房、处理后 ACK、对局和榜单顺序上报、Spout/云启动与移动端适配、断线重连。SDK 获取或配置受阻时交付已验证的独立部分并准确标记未完成项。
