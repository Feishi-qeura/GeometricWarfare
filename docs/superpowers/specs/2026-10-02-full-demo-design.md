# 几何战争五千人完整演示设计

用户已要求直接实现扩展，继续在现有 UE 5.8 项目工作，不重复请求实施授权。开发者名称 FEISHI。目标为可录制玩家视角视频的完整本地模拟对局；官方 SDK 和正式礼物仍待能力开通。

## 本次范围

- 8000 × 8000 正方形地图，至少容纳 5000 名观众。每个身份唯一，四形状与红蓝灰阵营延续原规则。
- 独立手枪数据，自动瞄准射击，资源球、中立静止 NPC、基地、积分转移及排行榜。
- 300 秒对局，240 秒基地全部摧毁，300 秒结算；30 秒展示胜利、MVP/FMVP 后自动开始新局，保留身份、阵营、形状，重置对局状态。
- 加入播报必须保留突发 50 条并依次显示，固定可复用显示槽向上移动并渐隐，不创建每条消息的 UObject/UI 控件。
- 社交范围为选队、阵营合作、加入播报、个人榜。用户已确认，不额外增加私聊或好友关系。
- 提案本地版本和 Chrome 中的飞书版本同步开发者名称及实际实现范围；无权限或浏览器连接失败时保留本地成果并说明具体阻碍。

## 可调整的默认数值

基地 2500 HP，NPC 200 HP / 25 分，原生球 2 分；手枪为独立配置。正方形中立特攻暂用于灰色观众与 NPC。三角形接触伤害 15，接触冷却 0.75 秒；同阵营无伤害。换形保留生命比例与武器计时，冷却 2 秒。

总分为各队当前持分之和；积分相同先比较队伍击杀，再按局号轮换红蓝优先，确保胜方为红或蓝。MVP 默认全场最高分，FMVP 默认胜方贡献最高：积分 + 击杀 × 25 + 对基地伤害 × 0.1；已向用户提问，可按回答调整。

## 性能架构

纯 C++ 连续内存保存角色与战斗数据，避免每观众一个 Actor。均匀网格裁剪碰撞和攻击候选，目标查找分批进行。所有角色参与模拟；概览省略密集昵称和头像，镜头缩放/跟随时恢复细节。头像占位共享小图集或有限纹理缓存，射击效果与加入播报使用固定容量复用。排名低频计算，不每帧排序。

根代理负责 UE 集成、HUD、摄像机交互、录制与浏览器；独立任务分别负责空间物理、战斗模型、提案。接口边界为 World、Match 和基于稳定 BodyId 的观众注册表。

## 验证

物理：5000 人生成、持续模拟、墙反弹及密集碰撞；报告本机实测时间而非仅声称支持人数。战斗：计时边界、比分守恒、复活、基地、形状属性、结算和下一局。UI：实际 UE 渲染截图，滚动播报压力测试，5000 人实际渲染与模拟性能采样。录制播放器可打开的 MP4 本地演示，注明模拟评论/礼物，不能当作正式 SDK 联调证据。
